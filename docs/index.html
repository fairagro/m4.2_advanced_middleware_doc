Answer

Harvester harvests an RDI catalog; SQL-to-ARC runs inside another RDI against its SQL database. Both upload RO-Crate ARCs to the Middleware API, which stores them and publishes to DataHUB; SearchHUB and SciWin consume in parallel.

  1. The Middleware API does not harvest; it accepts uploads, stores ARCs, and publishes.
  2. The API is the only write path into DataHUB for this family.
  3. SearchHUB and SciWin are external consumers; they are not implemented here.
  4. Box clicks stay on this map; open every standalone diagram from the catalog below.
